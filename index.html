Guide

How to Use Simple POS

Simple POS is a free, lightweight point-of-sale system for pop-ups, small vendors, markets and events. It runs in your browser with no account or backend, and keeps your products, orders, sales and payment details on this device.

No account No backend Local browser storage CSV import & export

Daily Use

Taking an order

  1. Select a category or use All Products.
  2. Tap a product to add it to the current order. Tap it again to increase the quantity.
  3. If you add an item accidentally, use the − button beside that item.
  4. Check the order total and the displayed order number.
  5. Tap Place Order.
  6. Use the order number to call the customer when their order is ready.
  7. Open Sales and tap Complete when the order has been handed over or fulfilled.
Order numbers are sequential for the day and reset for a new day. A completed order can be reopened if it was marked accidentally.
Tablet & Mobile

Using it on an iPad or phone

For tablets and phones, use the hosted version of Simple POS rather than opening the HTML file directly.

  1. Open the hosted site in your browser.
  2. On iPad or iPhone, open it in Safari.
  3. Use Add to Home Screen for a more app-like experience.

The desktop HTML file can also be opened directly in a desktop browser for testing or local use.

Products

Products & categories

Products are managed from Customize. Each product has a name, price and category.

  • Add, edit or delete products at any time.
  • Categories are created automatically from the categories used by your products.
  • All Products always shows the full catalogue.
  • If the last product in a category is removed or moved, that category disappears automatically.
  • Use Customize → Category Order to move categories up or down. All Products always remains first.
Bulk Setup

Import products from CSV

Use CSV import when you have many products to add. The file needs these columns:

Product name,Price,Category T-Shirt,2500,Clothing Cap,1500,Accessories Coffee,700,Drinks

You can download a template from Customize. When importing, you can either keep your existing products or replace the entire current product list.

Orders & Reporting

Sales dashboard

The Sales section gives you a quick view of the current day.

  • Revenue today
  • Total orders and open orders
  • Items sold
  • Product sales breakdown
  • Order numbers and completion status
  • The next order number

Use Export Today's CSV to save a detailed copy of the day's sales, including the date, order number, status, time, product, category, quantities, prices, totals and currency.

Customer Payment

Payment display

The Payment section is designed to be shown directly to a customer. In Customize → Payment Details you can add:

  • A payment QR code
  • Bank name
  • Account name
  • Account number
  • Branch
  • Transfer instructions or payment notes

When taking a payment, open Payment and turn the device toward the customer so they can scan the QR code or copy the transfer details.

Privacy

How Simple POS works

Simple POS is a static web application. It does not require a login, custom backend, database, cloud sync or external POS service.

Your order and configuration data stay in the browser's local storage. If the site is hosted online, the hosting provider still handles the normal web requests required to deliver the page itself.

Important

Data storage & backups

Simple POS stores its application data in the browser using localStorage. This includes your business name, currency settings, products, categories, current cart, sales history, order completion status, QR code and bank transfer details.

Refreshing or closing the page normally does not remove your data. However, different devices, browser profiles and website domains have separate local storage. Clearing browser or site data can remove your POS data.

For important events or sales periods, export the daily sales CSV regularly. Simple POS is intended for lightweight use and is not a replacement for a full accounting system or cloud-backed commercial POS.

Scope

Current limitations

The project is intentionally kept simple for pop-ups, markets, events and temporary sales setups. It currently does not include:

  • Multi-device syncing
  • Cloud backup
  • User accounts or staff permissions
  • Stock / inventory management
  • Integrated card payments
  • Receipt printing
  • Tax calculation
  • Refund workflows
  • Customer database
  • Kitchen / preparation screen
  • Automatic online backups
